Condiciones del servicio

Última actualización: 11 de octubre de 2026.

Al usar AsierKey (asierkey-2.vercel.app) aceptas estas condiciones.

El servicio

AsierKey permite a los usuarios con sesión iniciada crear y gestionar keys de acceso. El servicio se ofrece "tal cual", sin garantías de disponibilidad.

Uso aceptable

No puedes usar el servicio para actividades ilegales, para dañar a otros usuarios ni para saturar o atacar el sistema. Las keys creadas con contenido abusivo o enlaces fraudulentos pueden ser eliminadas.

Cuentas

Podemos suspender o eliminar cuentas y keys que incumplan estas condiciones.

Cambios

Podemos actualizar estas condiciones en cualquier momento. Seguir usando el servicio implica aceptar los cambios.
