AYUDA Y SOPORTE

Respuestas rápidas para los problemas habituales.

No puedo iniciar sesión

Comprueba el correo y la contraseña, y verifica que el servidor API esté desplegado.

No puedo crear una key

Inicia sesión y verifica que las variables de Redis/Upstash estén configuradas en el despliegue.

¿Dónde están mis enlaces?

Abre “Mis links” desde el menú. Los datos se solicitan a la API del proyecto.

Contacto

Prepara un mensaje con el error exacto, el navegador y los pasos para reproducirlo. No incluyas contraseñas ni tokens.
